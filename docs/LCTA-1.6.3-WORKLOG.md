# 1.6.3 修改与验收

## 修改范围

| 问题 | 处理 | 用户入口 |
|---|---|---|
| 称号、姓名混入正文 | 两块选区分别保存；角色信息单独翻译 | 框选正文、框选称号／姓名 |
| 游戏字体与选区影响识别 | 内置模型默认检测短边 640；限制 Windows 输入尺寸；底部预设包含多行文字 | 识别设置、手动选区 |
| 专名错字导致术语失配 | 游戏、语言、字段限定的整词纠错；精确术语直接用于角色字段 | 管理 OCR 纠错规则、个人术语 |
| 悬浮层没有层次 | 小号橙色角色信息、白色正文、状态提示；全文换行与滚动 | 悬浮层 |
| 服务与缓存状态不明 | 明示处理、缓存、错误分类，不保存原文或服务密钥到普通日志 | 首页状态、统计、诊断导出 |
| 旧结果难以纠正 | 重新识别当前区域，本次跳过缓存；新说话人视为新结果 | 重新翻译、控制条重译 |
| 日语完全无法识别 | Windows 缺少日语包时使用内置模型；不使用英语代替日语 OCR | 日 → 中 |

另外修复编辑模式下默认拖动控件遮挡正文，并保留主界面 4 DIP 橙色边框和文字间距。

## 分区约定

正文区域不应包含角色信息。称号／姓名区域的最后一行视为姓名，前面的行合并为称号；单行角色信息原样作为一个字段翻译。区域按目标窗口及框选时客户区尺寸保存。网页可只使用正文区域。

未知称号和姓名交给已配置的翻译服务，已命中的精确术语直接采用用户或档案译名。字符纠错不做普遍的模糊猜测，维护者可补充有实际截图依据的规则。
