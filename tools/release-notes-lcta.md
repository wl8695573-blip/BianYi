# LCTA 1.6.5

修复旧角色选区把称号和姓名合在姓名字段中的问题。

- 同时读取半角和全角分隔符，先拆分字段再进行称号、姓名纠错。
- 旧合并选区也能正确将“グンテ”纠正为“ダンテ”，并匹配“但丁”。
- 译文框和悬浮层去掉“称号：”“姓名：”“正文：”标签，保留实际内容与排版层次。
- 原文框保留字段标签，方便检查识别结果。
- 保留原有选区、服务配置、密钥和个人术语。

## 使用

退出旧程序后升级，再开始翻译。原选区已经完整覆盖文字时可直接使用；修改选区或需要生成新结果时点击“重新翻译”。

## 下载

- 安装版：`LCTA-Setup-1.6.5.exe`，安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.5.zip`，完整解压并保留 DLL、模型与词库。
- 校验文件：`SHA256SUMS-1.6.5.txt`。
