# LCTA 1.6.4

称号、姓名和正文改为三个独立识别区域，分别框选、保存和翻译。

- 使用“称号：”“姓名：”“正文：”格式显示原文与译文。
- 正文 OCR 排除角色区域，避免名字重复混入台词。
- 修复但丁的日语姓名被识别为“グンテ”后无法匹配术语的问题，新增仅用于该游戏日语姓名的整字段纠错。
- 纠错规则支持称号、姓名与正文分别设置，并保留旧规则兼容。
- 保留旧配置、密钥、个人术语与合并角色选区的读取兼容。
- 调整最小窗口下的译文区高度。

## 使用

先点击“框选正文”，再分别点击“框选称号”“框选姓名”。每块只框对应文字；游戏布局改变后重新框选。修改后点击“重新翻译”生成新结果。

## 下载

- 安装版：`LCTA-Setup-1.6.4.exe`，退出旧程序后安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.4.zip`，完整解压并保留 DLL、模型与词库。
- 校验文件：`SHA256SUMS-1.6.4.txt`。

已用用户提供的实际日语画面检查三个字段的识别与翻译，并执行回归、交互及安装升级检查。具体范围见 `docs/VERIFICATION.md`。
