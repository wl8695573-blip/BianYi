# LCTA 1.6.3

本次修复日语识别失败，并将角色信息与正文分开处理。

- 分别框选并保存正文与称号／姓名区；边狱巴士自动底部预设支持分区。
- 悬浮层显示较小的橙色“称号｜姓名”和较大的白色正文。
- 缺少日语 Windows OCR 时使用内置模型，不再回退为英语识别。
- 增加按游戏、语言和字段生效的 OCR 纠错规则及管理窗口。
- 主界面和控制条可重新翻译当前句，本次跳过缓存。
- 显示处理与错误状态，长译文不再按最大行数截断。
- 修复编辑模式下默认拖动控件的白色外观遮住译文的问题。
- 主窗口橙色边框加粗至 4 DIP，保留文字边距。

## 下载与升级

- 安装版：`LCTA-Setup-1.6.3.exe`。退出旧程序后安装到原登记目录。
- 便携版：`LCTA-win-x64-1.6.3.zip`。完整解压，运行 `LCTA/LCTA.exe`，保留 DLL、模型与词库。
- 校验值：`SHA256SUMS-1.6.3.txt`。

沿用已有配置、密钥与个人术语。首次使用分区识别，先重新框选正文，再框选称号／姓名；只有正文也可正常使用。

已使用实际边狱巴士日语画面及用户提供的英文截图检查识别与翻译，并执行隔离配置下的回归和交互检查。真实游戏截图与账户配置未随源码发布。完整记录见 `docs/VERIFICATION.md`。
