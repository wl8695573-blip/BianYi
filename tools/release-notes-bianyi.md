# 边译 1.7.0

由 GuGuGaGaTranslator、LCTA 延续开发，软件名称统一为“边译”。

- 主界面、悬浮球导航、首次设置、安装器和快捷方式同步更名，程序为 `BianYi.exe`。
- 移除历史公共术语集合，接入独立整理、逐条记录依据的 17 条基础语言映射。当前不是完整游戏专名库，更多专名可通过个人术语或社区反馈补充。
- 词库升级替换未修改的旧默认条目，保留个人译名、禁用、备注和新增条目。
- 修正 Sakura 提示格式固定日译中与其他方向冲突的问题，加强目标语言要求并避开旧提示缓存。
- 沿用旧配置和安装身份，支持升级、独立词库更新和四语互译。专用模型支持的方向以模型能力为准。

## 下载与升级

- 安装版：`BianYi-Setup-1.7.0.exe`。退出旧程序后安装到原登记目录。
- 便携版：`BianYi-win-x64-1.7.0.zip`。完整解压后运行 `BianYi/BianYi.exe`，保留 DLL、模型与词库。
- 校验：`SHA256SUMS-1.7.0.txt`。
- `LCTA-Setup-1.7.0.exe` 供旧版更新器识别，与边译安装器内容相同；新下载选择边译安装版即可。

软件与术语更新仍通过原仓库提供，保留旧链接兼容。新的基础词库来源见 `terminology/sources/library/README.md`。

## 验证范围

发布前重新执行回归、完整交互、四语 OCR、实际日语截图和真实在线服务检查，再对安装版与便携版进行包验收。结果与限制见 `docs/VERIFICATION.md`；本次证据不能代表全部显卡、游戏、网络或模型的效果。
