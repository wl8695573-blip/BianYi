# 边译 1.7.1

## 选区操作

- 移除称号、姓名的单独框选与清除按钮，保留“框选区域”，增加统一“重置框选”。
- 重置清除当前窗口的正文、称号、姓名与旧合并选区，保存后重启不恢复旧框选；保留其他窗口选区、术语、语言、服务配置和悬浮窗位置。
- 边狱巴士默认剧情布局自动划分正文与人物信息，人物首行显示“称号｜姓名”，下方显示正文。手动正文区域仍优先。
- 悬浮球菜单增加“重置框选”。保存失败时显示提示。

## 下载

- 安装版：`BianYi-Setup-1.7.1.exe`。先退出旧程序，再安装到原目录。
- 便携版：`BianYi-win-x64-1.7.1.zip`。完整解压后运行 `BianYi/BianYi.exe`。
- 校验：`SHA256SUMS-1.7.1.txt`。
- `LCTA-Setup-1.7.1.exe` 是旧文件名兼容入口，与边译安装器内容相同。

仓库现名为 BianYi，新版更新器兼容新旧地址。旧版若因地址校验无法下载，请从本页手动下载安装。
